# Traspaso Paid Media · Wasabi

Página interna con el traspaso de cuentas de Paid Media: una pestaña por marca, índice por sección y buscador entre marcas.

**Marcas cargadas (10):** AFAP SURA, Artesia, E-Travels, Espacio Mascota, Foquier, Los Leños, Los Nietitos, Ramona, SYLAB y TopLine.

## Uso
Abrir `index.html` en el navegador. Es un único archivo, sin servidor.

## Actualizar una marca
Las marcas están en la lista `BRANDS` al inicio del script de `index.html`. Para cambiar una, editar su objeto o regenerarlo desde el documento maestro actualizado.

## Importante: uso interno
Contiene IDs de cuentas publicitarias, links internos de SharePoint y Drive, presupuestos y estrategia de clientes. Mantener este repositorio **privado** y no publicarlo como sitio abierto (GitHub Pages).
